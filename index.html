시험범위 AI 기출 예측 연구소

시험 범위를 입력하면 조사할 자료, 검색 링크, AI 분석 요청문을 만들어 줍니다.

① 시험 정보 입력

입력한 내용은 이 파일 안에서만 처리되며 별도 서버로 전송되지 않습니다.

② 사용 방법

1. 시험 범위 입력과목과 시험 범위를 적습니다.
2. 요청문 생성AI가 조사할 작업을 정리합니다.
3. 자료 검색관련 기출과 교과 자료를 검색합니다.
4. ChatGPT에 전달요청문을 붙여넣으면 분석을 진행합니다.
중요한 작동 방식
API 키 없이 실행되는 HTML 프로그램입니다. 독립 실행 파일이 ChatGPT의 웹 검색 기능을 직접 호출할 수는 없습니다. 대신 검색 링크와 복사용 요청문을 만들고, ChatGPT에서 실제 조사와 문제 제작을 진행하도록 설계했습니다.

AI에게 요청하는 분석

  • 교과서·교육 자료·공개 기출 조사
  • 출처와 실제 기출 여부 표시
  • 중요 개념 및 출제 유형 분석
  • 난이도별 예상문제 제작
  • 정답·해설 및 암기 체크리스트
  • 확인된 사실과 AI 추론 구분
